Enforces min and max withdrawal limits for eSewa in user wallet (e.g. Min 100, Max 500 NPR).

Shows update notice dialog with app logo, custom notice title, description, and "Update App Now" button linking to your download link.

✨ Smart Version Filtering: If you set version to 1.1, users who download or are already running version 1.1 will NOT see the update notice! Older versions (1.0) will see it.
